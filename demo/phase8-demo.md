# 五分钟面试演示脚本

## 演示准备

```bash
npm ci
cp .env.example .env.local
npm run dev
```

浏览器打开 `http://127.0.0.1:3000`。为稳定展示人工审核路径，可暂不配置 Embedding Key；演示数据位于 `demo/phase8-source/`。

## 0:00 - 0:40：问题与边界

打开首页，说明项目不是聊天机器人，而是本地知识整理 Agent。指出状态页展示来源健康、队列、最近处理阶段、耗时与 LLM/Embedding 分项降级。

一句话：系统把“散落文件”转换为“有稳定身份、经过质量审查、能追溯来源的知识”。

## 0:40 - 1:30：观察来源

进入“设置 → 来源监听”，新增自定义来源：

- 名称：`Phase 8 演示来源`
- 类型：`Markdown`
- 路径：仓库中 `demo/phase8-source` 的绝对路径
- 包含规则：`*.md`
- 固定主题：`learning`

保存后点击“扫描所有来源”。解释 `sourceId` 由来源身份稳定生成，`revision` 由内容生成；再次扫描同一文件不会创建副本。

## 1:30 - 2:20：决策与人工恢复

返回状态页观察 `discovered → parsing → normalizing → staged → processing`。未配置 Embedding 时，候选会进入 `review`，原因码为 `VECTOR_RECALL_UNAVAILABLE`。

进入审核工作台，对照来源摘录、来源版本、候选正文和原因。可以现场编辑一行，然后“保存并接受”；也可以直接“接受候选”。强调人工接受仍复用原 memoryId，不绕过发布和索引同步。

## 2:20 - 3:20：发布与直接阅读

进入检索库，搜索 `KnowledgeAgent 循环`。页面显示关键词降级通道、最终分数、主题和来源。打开知识详情，展示 Markdown 正文与记录信息。

说明正常配置模型时，搜索还会使用原句与查询改写、向量召回、Wikilink 邻居和 MMR 重排；改写失败自动退回原句。

## 3:20 - 4:10：主题资料与追溯

点击“话题：学习笔记”。展示确定性生成的大纲、章节、“本节依据”知识链接和来源版本表。沿知识链接返回详情，完成“结论 → 知识 → 来源”的追溯。

强调模型只能调整章节标题和顺序，不能加入没有合法知识引用的新事实。

## 4:10 - 4:40：幂等与故障行为

再次点击“扫描所有来源”，刷新检索库，确认仍只有一条同名知识。说明：

- LLM 失败：转人工审核。
- Embedding 失败：既有知识仍可关键词检索。
- processing 中断：同一事件恢复并递增 attempt。
- HNSW 损坏：从 SQLite 向量真源重建，不改 Markdown。

## 4:40 - 5:00：工程证据

展示 `docs/specs/001-local-knowledge-agent/phase-8-delivery.md`：改造前后代码/路由/依赖、覆盖率、检索指标、0% 重复率，以及格式、类型、Lint、覆盖率、评测、构建和 Playwright 门禁结果。

自动化复现同一主流程：

```bash
npm run test:e2e
```
