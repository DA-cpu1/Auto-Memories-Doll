## 7. Phase 0 修复记录

### 7.1 聊天模式恢复竞争

问题：`useChatSession` 在 `hydrating=true` 时仍允许用户点击模式按钮。用户切换到记忆模式后，异步恢复结果会把模式重新覆盖为 `chat`，导致刚出现的移动端“选择记忆”按钮从 DOM 中卸载。

修复：`ChatModeSelector` 增加 `disabled` 契约，`ChatInterface` 在会话恢复或消息处理中禁用模式切换，并增加静态渲染回归断言。真实移动端 E2E 已通过。

### 7.2 图谱 E2E 契约过期

问题：知识图谱的筛选面板已经改为默认折叠，但旧 E2E 直接查找只在展开后渲染的搜索框。

修复：测试改为按真实用户流程点击“显示筛选”，再验证“搜索知识节点”输入框。页面实现无需修改。

### 7.3 Windows E2E 进程清理

Playwright 在 Windows 上通过 `taskkill` 清理 webServer 进程树。在受限沙箱内运行时该系统调用会被阻止，表现为测试已经通过但命令停在 plugin teardown。允许测试进程清理权限后，完整 E2E 在 41.1 秒内正常退出。项目的启动器和 `globalTeardown` 无需修改。

### 7.4 Lockfile 一致性

改造前 stash 中的 `package-lock.json` 修复已恢复：`usearch` 与 `package.json` 一致地记录为固定版本的 optional dependency，并补充 npm 生成的依赖标记。该修改属于依赖清单一致性，不改变产品行为。
