## 交付结果

首页现在是处理状态工作台，展示来源健康、最近来源版本、监听数量、队列数量、最近阶段、处理结果、耗时和降级能力。全局降级提示分别说明 LLM 与 Embedding 的影响，不再只暴露一个模糊布尔状态。

来源设置支持预设或自定义新增、完整字段编辑、启停、移除和手动扫描。开关使用带可访问名称的 `switch` 语义，设置导航通过 `aria-current` 暴露选中态。

搜索 API 在原有记忆字段上增加 `score` 和 `channels`，检索库与首页展示最终分数、主题、来源和实际命中通道。Embedding 降级时继续明确显示关键词通道。

主题页面改为读取 Phase 6 的 `/api/topics/[topic]`，展示有序大纲、章节正文、知识链接、来源路径、来源类型、revision 和采集时间。资料尚未生成时可以从已发布知识生成确定性资料。

审核页改为裁决工作台。待审核候选同时显示来源摘录、来源版本、候选正文、结构化原因码和人类可读原因，并支持接受、编辑后接受和拒绝。字段冲突保留现有值、候选值、手动合并值三种裁决路径。

## 设计与可访问性

界面采用高信息密度的本地档案工作台风格，以纸白、炭黑、青绿为主体，琥珀和红色只承担等待与错误状态。共享圆角收敛到 8px，按钮补齐统一的尺寸、焦点和禁用态。

导航、视图切换、来源开关、表单和数据表均使用语义元素与标签。窄屏布局使用单列和可控的局部横向滚动，页面本身不产生横向溢出。`prefers-reduced-motion` 继续关闭非必要动画。
