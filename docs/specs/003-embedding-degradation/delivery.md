## 交付行为

Embedding 可显式关闭且配置持久化。向量不可用时继续质量检查和提取；精确正文身份保留中文、数字、符号和否定词，关键词提示不伪装成 cosine。LLM 依赖故障写入 waiting_dependency，记录槽位、阶段、原因、尝试时间、预算与暂停状态，恢复沿用原事件。质量不确定、证据不足及非事实内容仍进入人工审核。

恢复间隔集中配置为 1、5、20 分钟，初始尝试加最多三次自动重试；每批上限 20 条。配置问题直接暂停，配置变化或明确重试可以重新检查。成功的话题、质量与提取结果按候选、模型和策略版本存入检查点。更新期间保留旧知识，发布前核对版本并保存快照。

向量补建只改向量索引和其状态，回写前检查当前内容、模型、维度和开关。审核页分别展示等待候选、向量状态和旧故障预览。旧队列操作有持久化批次、状态重验、暂停及继续，Codex 缺筛选版本证据时跳过。

批量预览与确认区已移到审核页标题之后、候选列表之前。页面从 API 恢复最新持久化批次，直接显示带候选数量的确认按钮；确认后刷新审核列表，运行中每五秒刷新提交进度。预览明细使用中文原因，等待列表限制显示高度。新增 326 条模拟候选的 Playwright 验收，覆盖首屏可见、手机布局、刷新保留预览和点击执行。测试构建目录与日常服务隔离，避免多个 Next.js 服务共享 `.next` 导致页面脚本失效。本次未点击真实积压的执行按钮。

### 连接测试修复（2026-09-05）

实际运行服务曾继承启动环境的网络沙箱限制，导致 EACCES；在正常网络权限下重启后连接恢复。随后发现设置页测试接口未还原 GET 配置返回的脱敏 Key，向提供商发送星号而产生鉴权错误。现已按已保存的 Key 与端点回填；脱敏值过期或测试端点发生变化时本地拒绝发送凭据。共享与独立 Embedding 凭据均有回归测试。HTTP 200 内的 MiniMax base_resp 业务错误现在明确显示代码与脱敏原因，测试结果保留至下一次测试或配置编辑。

设置页按钮实测语言模型返回“MiniMax-M2.7 响应正常”；现存 Embedding 端点返回 2013，要求 texts 参数，与当前 OpenAI 兼容 input 请求不匹配。未擅自修改模型、端点、Key 或 Embedding 开关。定向 14 条测试、设置页脱敏凭据 Playwright 流程、typecheck 与 lint 通过。

### 最终 JSON 解析修复（2026-09-05）

用合成 TypeScript/JSON 知识复现：MiniMax 响应正常结束，但正文含 `<think>` 思考段，段内代码带花括号。旧质量解析将第一个左花括号到最后一个右花括号整体送入 JSON.parse，误把思考与最终答案拼接而产生 INVALID_OUTPUT。修复后同类真实响应仍会使旧截取方式失败，但新解析器能正确读取最终 JSON。

新增共享 `parseModelObject`，只剥离明确闭合的前置思考段，再解析完整最终 JSON 或单一 JSON 代码块；不接受未闭合思考、仅有思考示例、多对象或残缺响应。质量、抽取和话题分类共用该规则。质量检查不采用思考段评分，截断响应标记 OUTPUT_TRUNCATED；实际 SDK 调用传入配置的输出 token 上限及温度。加工检查点策略升级为 ka-003-final-json-v2。

44 条定向测试及全量覆盖率门禁通过，typecheck、lint、死代码门禁通过。正常网络权限下重启后台进程后，分两批恢复 20 条解析失败候选及 19 条在重启前已因旧解析失败暂停的候选，沿用原事件。已核对恢复范围内至少 1 条完成发布，规范 Markdown 存在且正文不含思考标签；其余按原质量与审计流程继续，不承诺全部自动入库。
