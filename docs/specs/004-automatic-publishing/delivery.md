2026-09-09。本次替代历史文档中的价值评分、人工筛选和人工冲突裁决规则。

## 行为

- 取消 QualityFilterService、质量/证据/kind 入库闸门和向量/Jaccard/跨来源精确重复拒绝。相同来源版本仍保持幂等；不同来源的相同正文可以各自保存。
- 非空短消息照常处理，包括单字符文件。保留既有工具会话的真实用户输入/最终回答白名单、格式校验和密钥脱敏。
- AI 继续负责整理和拆卡，不决定内容是否值得保存。首卡保留来源原文，使模型摘要遗漏的简单事实仍能被搜索。
- 同一 ID 的更新按 updatedAt 使用较新候选的已声明字段；旧候选不得覆盖较新内容或删除其分卡。覆盖前保存 SQLite 快照和 archive/versions 下的 Markdown 快照，记录 snapshotPath。
- Markdown 写入失败进入 failed，不伪报 done；原事件可重试修复。Embedding 失败不阻止笔记发布，关键词检索继续工作，向量单独补建。
- 模型整理失败自动保存完整原文，事件正常完成；无需等待模型恢复。模型恢复后，新任务仍正常使用 AI 整理。已保存的原文不自动重新改写。

## 迁移和接口

队列每批消费前将旧 review、质量/抽取阶段 waiting_dependency，以及有未解决冲突的旧 done 事件重新置为 pending。只在发布成功后完成旧冲突记录。迁移幂等，保留稳定事件 ID；已有 rejected 历史不自动重新发布。无关联队列事件的历史冲突记录仅留作历史凭证。

删除 /audit 页面和 /api/audit、/api/audit/conflicts、/api/audit/review-events、/api/audit/dependencies。审核菜单、首页快捷入口、设置页审核链接和人工决策方法一并删除。原入口返回 404。

记忆创建/更新接口先返回 queued，后台完成后才视为发布成功；不会在仅入队时返回 written。监听状态接口改为 pending、processing、done、failed、waiting_dependency 五类统计。首页解释各类状态并展示处理中和已完成任务数，数量为事件数而非消息条数。
