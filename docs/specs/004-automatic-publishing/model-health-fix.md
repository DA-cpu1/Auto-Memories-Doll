# 模型降级误报与恢复检查修复

2026-09-10。

首页原先汇总最近五条历史 AgentProgressEvent.degradedCapabilities，并显示为“当前降级能力”。历史失败即使已经恢复，也会继续被呈现为当前故障。删除这处重复提示，统一使用全局组件轮询的 /api/health；历史事件仍保留原始诊断。

健康接口增加 failures，包含模型槽位、模型名、原因、时间、耗时及请求用途，不包含密钥、端点或请求/响应正文。实时故障由当前配置指纹下的失败记录决定；退避期结束只允许重试，成功请求后才清除故障。配置改变时旧请求结果不得污染新配置。

自动恢复检查只对有失败记录、退避结束、没有活跃或排队请求的槽位执行。各槽位串行检查，文字模型使用最多 128 输出 token、零 SDK 重试的短请求。健康模型不再每 30 秒产生额外模型调用。认证失败仍需修正配置，不反复自动尝试。

设置页明确连接测试只检查表单中的普通模型与向量模型。它是独立基础连通性测试，既不保存配置，也不清除后台其他档位的故障。后台使用已保存配置；长文本整理以真实调用结果为准。
